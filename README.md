📘 OCR Dictionary App  
An Intelligent Image-to-Text Dictionary with Translation & Pronunciation



 🌟 Overview

The OCR Dictionary App is a smart web application that extracts text from images using **Optical Character Recognition (OCR)**, translates the detected text, and generates **pronunciation audio** for better language understanding.

This project combines FastAPI (backend) and a simple web frontend to deliver a clean, fast, and interactive user experience.



✨ Key Features

- 📷 Image upload for text recognition  
- 🔍 Accurate OCR using Tesseract
- 🌍 Language translation support  
- 🔊 Pronunciation audio generation  
- ⚡ FastAPI-based REST API  
- 🖥️ Lightweight HTML/CSS/JS frontend  
- 🔐 CORS-enabled backend
